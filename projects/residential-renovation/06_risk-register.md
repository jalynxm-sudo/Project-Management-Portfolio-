# Residential Kitchen Renovation — Project Risk Register

## Project Overview

**Project:** Simulated Residential Kitchen Renovation  
**Project Type:** Residential Construction / Renovation  
**Document:** Project Risk Register  
**Status:** Preliminary  
**Prepared By:** Project Manager  
**Project Context:** Fictional portfolio project created to demonstrate project planning and risk management.

## Purpose

This risk register identifies potential events that could affect the renovation project's schedule, budget, quality, safety, or homeowner satisfaction.

The project manager will monitor identified risks, coordinate appropriate responses, and update the register as new information becomes available.

All risks and response plans in this document are simulated for portfolio demonstration purposes.

## Risk Rating Method

### Probability

| Rating | Description |
|---|---|
| Low | Unlikely to occur |
| Medium | Could reasonably occur |
| High | Likely to occur |

### Impact

| Rating | Description |
|---|---|
| Low | Limited effect on project outcomes |
| Medium | Noticeable effect on cost, schedule, or quality |
| High | Significant effect on project outcomes |

## Risk Response Plan

| ID | Mitigation / Response | Responsible Party | Monitoring |
|---|---|---|---|
| R-01 | Conduct an initial site assessment, document existing conditions, and establish a process for reviewing unexpected discoveries before additional work proceeds | Project Manager and Contractor | Review demolition findings and document approved changes |
| R-02 | Confirm lead times before scheduling installation and track critical material delivery dates | Project Manager and Supplier | Review procurement status during project check-ins |
| R-03 | Maintain a preliminary budget, track estimated versus actual costs, and use contingency only through an approved decision process | Project Manager | Review budget updates and cost changes |
| R-04 | Document approved design selections and establish a change-request process | Project Manager and Homeowner | Record changes, approvals, and schedule effects |
| R-05 | Confirm contractor availability and coordinate work sequencing before construction activities begin | Project Manager and Contractor | Review upcoming work and resource availability |
| R-06 | Identify applicable permit and inspection requirements before construction and track required approvals | Project Manager and Contractor | Review permit and inspection status |
| R-07 | Confirm material specifications, inspect delivered materials, and document discrepancies | Contractor and Project Manager | Review deliveries and installation quality |
| R-08 | Establish regular project updates, document decisions, and maintain a shared action-item list | Project Manager | Review communication records and outstanding decisions |
| R-09 | Require appropriate site safety practices and coordination with qualified construction professionals | Contractor and Site Personnel | Monitor reported safety concerns and corrective actions |
| R-10 | Conduct a final walkthrough, document deficiencies, and track corrective work before project acceptance | Project Manager, Contractor, and Homeowner | Review punch-list completion and acceptance status |

## Risk Monitoring Approach

The project manager will:

1. Review the risk register during project planning and scheduled project check-ins.
2. Identify new risks as design, procurement, and construction activities progress.
3. Document changes in probability, impact, and response plans.
4. Escalate significant cost, schedule, safety, or quality concerns to the appropriate stakeholders.
5. Track mitigation actions and responsible parties.
6. Update the register when risks are resolved or new information becomes available.

## Risk Escalation

Risks requiring additional review include:

- Potential changes to the approved project scope.
- Significant budget increases.
- Delays affecting major project milestones.
- Permit or inspection concerns.
- Safety incidents or unsafe working conditions.
- Material or workmanship issues requiring corrective action.

The project manager will document the issue, communicate with the appropriate stakeholders, and coordinate a response before proceeding with affected work when necessary.

## Portfolio Reflection

This document demonstrates how a project manager can identify potential construction risks, evaluate their possible effects, assign responsibility, and establish response strategies.

The register is a planning tool rather than a guarantee that risks will be prevented.
