# Residential Kitchen Renovation — Project Change Request Log

## Project Overview

**Project:** Simulated Residential Kitchen Renovation  
**Project Type:** Residential Construction / Renovation  
**Document:** Project Change Request Log  
**Status:** Preliminary  
**Prepared By:** Project Manager  
**Project Context:** Fictional portfolio project created to demonstrate project management practices.

## Purpose

This change request log documents proposed changes to the original renovation scope.

The project manager will evaluate each request for its potential effect on:

- Project scope
- Budget
- Schedule
- Materials and procurement
- Quality
- Homeowner expectations

Changes will be documented and reviewed before being incorporated into the project plan.

All requests and estimates below are simulated for portfolio demonstration purposes.

## Change Request Process

1. Document the requested change.
2. Identify the reason for the request.
3. Evaluate potential scope, budget, and schedule impacts.
4. Review the request with the appropriate stakeholders.
5. Record the approval or rejection decision.
6. Update relevant project documents after approval.
7. Communicate the decision and next steps.

## Change Request Evaluation

### CR-001 — Countertop Material Upgrade

**Request:** Replace the originally planned countertop selection with an upgraded material.

**Reason:** Homeowner preference.

**Potential Impact:**
- Updated material pricing may increase the project budget.
- Supplier availability and lead time may change.
- Installation requirements may affect construction sequencing.

**Project Manager Response:**
Obtain updated material pricing and availability. Review the proposed change with the homeowner and assess its effect on the budget and schedule before approval.

**Decision:** Pending review.

### CR-002 — Additional Kitchen Lighting

**Request:** Add additional task lighting to the kitchen.

**Reason:** Improve visibility and functionality.

**Potential Impact:**
- Additional fixtures and materials may be required.
- Electrical work may need to be reviewed by a qualified professional.
- Installation may affect work sequencing.

**Project Manager Response:**
Document the requested lighting locations, coordinate with the qualified electrical contractor, and obtain an updated estimate and schedule assessment.

**Decision:** Pending review.

### CR-003 — Backsplash Selection Change

**Request:** Replace the original backsplash selection with a different tile design.

**Reason:** Homeowner design preference.

**Potential Impact:**
- Material pricing may change.
- New material availability must be confirmed.
- Installation timing may be affected.

**Project Manager Response:**
Confirm the revised selection, obtain updated pricing, and evaluate whether the change affects procurement or installation activities.

**Decision:** Pending review.

## Change Approval Requirements

Before a change is incorporated into the project plan, the project manager should document:

- Description of the requested change
- Reason for the change
- Updated cost estimate
- Schedule impact
- Required stakeholder review
- Approval or rejection decision
- Date of decision
- Related project documents requiring updates

The project manager should not treat a proposed change as approved until the required decision has been documented.

## Project Document Updates

Approved changes may require updates to:

- Homeowner requirements
- Project scope
- Work breakdown structure
- Project schedule
- Project budget
- Procurement plan
- Risk register

The project manager will communicate approved changes to the appropriate stakeholders and maintain consistent project documentation.
