# Luxury Art Nouveau Condo — Blender Architectural Modeling

### 3D Building Modeling | Spatial Design | Project Development

## Project Overview

**Project Type:** Self-Directed 3D Architectural Modeling  
**Software:** Blender  
**Design Direction:** Luxury Art Nouveau residential building  
**Project Status:** In Progress  
**Role:** 3D Modeler and Project Planner

## Project Vision

This project explores the development of a detailed, multi-level residential building inspired by Art Nouveau architecture and luxury interior design.

The goal is to develop a cohesive building model that combines structural forms, residential layouts, architectural details, and selected building systems into one organized 3D project.

The project is being developed incrementally, with building elements organized into collections and constructed through defined modeling milestones.

## Design Goals

The planned design direction includes:

- A distinctive Art Nouveau architectural style
- Multiple residential levels
- Thoughtfully organized living spaces
- Curved architectural features and decorative detailing
- Kitchen and bedroom layouts designed around natural light
- Luxury common areas, including a lobby and resident amenities
- Parking and building circulation
- Selected HVAC and building-service elements
- Accessible-unit design considerations

These are project goals; they should not be interpreted as completed features unless they are present in the current model.

## Modeling Workflow

The project is developed through a structured sequence:

1. Establish the building's overall dimensions and organization.
2. Create foundational slabs and major building geometry.
3. Develop perimeter walls, openings, and circulation.
4. Model stairs and connections between levels.
5. Add architectural details and interior layouts.
6. Develop selected building systems.
7. Refine materials, lighting, cameras, and presentation views.
8. Review the model and document progress.

## Project Organization

The Blender project uses named collections to organize building components and systems.

This organization supports a more manageable workflow by separating elements into logical groups and making individual components easier to locate and revise.

## Current Progress

The project is under active development. Building geometry and stair components have been modeled, and the structure is being reviewed as additional elements are developed.

**Current limitations:** The model is not represented as a completed, construction-ready architectural design. Dimensions, connections, building systems, accessibility provisions, and other technical requirements would need appropriate professional review before real-world use.
